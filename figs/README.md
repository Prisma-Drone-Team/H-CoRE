# H-CoRE Framework Figures

This directory contains visual assets for the H-CoRE framework documentation.

## Required Images

### h-core_simu.png  
**Description**: Screenshot of the H-CoRE multi-robot simulation environment showing:
- UAV (baby_k drone model) positioned in 3D space
- UGV (rover) on ground terrain
- Gazebo Garden simulation environment with realistic physics
- Multiple sensor visualizations (LiDAR, camera, depth sensors)
- RViz interface showing navigation planning and coordination

**Usage**: [Simulation Tutorial](../tutorials/sitl_setup.md)

### h-core_hardware_deployment.png
**Description**: Photograph of the H-CoRE framework real hardware deployment showing:
- Actual UAV hardware platform (quadcopter with companion computer)
- Real UGV platform with navigation sensors (LiDAR, cameras)  
- Operational environment setup (testing area or field)
- Ground Control Station setup with monitoring displays
- Clear view of actual hardware integration and deployment

**Usage**: [Hardware Deployment Tutorial](../tutorials/hardware_deployment.md)

## Image Specifications

- **File Format**: PNG (preferred) or JPEG
- **Resolution**: Minimum 1280x720, recommended 1920x1080
- **Compression**: Balanced compression maintaining visual quality
- **Naming Convention**: Descriptive lowercase names with underscores
- **Documentation**: Update this README when adding new images

## Content Requirements

### For Simulation Images (h-core_simu.png)
- Clear view of both UAV and UGV agents
- Visible sensor data (point clouds, camera feeds)
- Navigation paths and goal markers
- Professional presentation suitable for technical documentation

### For Hardware Images (h-core_hardware_deployment.png)
- Clear view of both UAV and UGV hardware agents

## Capture Instructions

### Simulation Screenshot
1. Launch multi-robot simulation as described in the tutorial
2. Position camera to show both agents clearly
3. Enable all relevant RViz visualizations
4. Capture during active mission execution for dynamic appearance
5. Ensure simulation timestamp and status indicators are visible

### Hardware Photography
1. Setup hardware agents in operational configuration
2. Position camera to show both agents and environment clearly  
3. Include GCS setup and monitoring displays if visible
4. Capture during active operation for dynamic appearance
5. Ensure good lighting and system identification visibility
